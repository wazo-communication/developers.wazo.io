# Documentation

**Wazo Shift**, our new mobile app, comes with a new plugin system. It is more powerful than the one in Wazo Mobile Legacy and is available through our whitelabel offer.

Want to extend Wazo Shift, or bring an existing mobile plugin to it? Please reach out to your Wazo contact to learn more about this plugin system and what it can do for your users.

:::note
Plugins built for Wazo Mobile Legacy do not run in Wazo Shift. See [Mobile Plugin (Legacy)](/docs/plugins/ui/mobile).
:::
